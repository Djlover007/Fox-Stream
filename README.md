# Fox Stream

Dein Unterhaltungshub fürs Handy: nur legale, kostenlose Streaming-Angebote an einem Ort. Design by Mr.Fox.

- **Heute:** Live-TV mit einem Tipp (Das Erste, ZDF, Pluto TV, Joyn) und was heute auf deinem Plan steht
- **Woche:** Wochen-Watchlist mit Genre-Filter, Sendezeiten und Häkchen für „gesehen“
- **Sender:** alle Gratis-Plattformen mit Hinweisen wie „werbefrei“, „ohne Konto“, „nur DE“
- **Merkliste:** eigene Titel merken, abhaken, löschen
- **Suche:** Titel direkt in JustWatch, ARD, ZDF oder ARTE suchen

Links öffnen direkt die installierte App des Senders, sonst den Browser.

Die APK baut GitHub Actions bei jedem Push auf `main` und hängt sie an ein Release. Updates kommen danach direkt über die App.
